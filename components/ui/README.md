# UI Components

This folder contains all the low-level UI primitives generated by `shadcn/ui` (style: `base-nova`, on top of `@base-ui/react`).

**Do not hand-edit these files** unless you are intentionally modifying the core design system.
Instead, import them into your feature components and compose them or override their styles via `className`.

## Design-system adjustments (intentional)

The stock `base-nova` sizing is tuned for dense/mobile UI. We've re-tuned it for a desktop-first product feel:

| Primitive | Stock | Ours |
|---|---|---|
| `Button` default / `lg` / `sm` | 32 / 36 / 28 px | **40 / 48 / 34 px**, primary has a soft glow shadow |
| `Input`, `SelectTrigger` | 32 px, transparent | **40 px**, card surface, hover border |
| `TabsList` / `TabsTrigger` | 32 px | **44 px**, active tab is an elevated card |
| `Card` | `rounded-xl`, 16 px padding | **`rounded-2xl`, 24 px padding**, `shadow-elevated` |
| `Dialog` | `max-w-sm`, 16 px padding | **`max-w-md`, 24 px padding**, darker blurred backdrop |
| `Switch` | 18 × 32 px | **24 × 44 px** |
| `Badge` | 20 px | **24 px**, pill |

Theme tokens (`--primary`, `--card`, `--glow-*` …) live in `app/globals.css`. Dark mode is the default and is driven by `next-themes` via the `.dark` class (see `components/theme/`).

## Installed Primitives

- `alert`: For displaying inline warning/info states.
- `avatar`: For displaying user or guardian avatars.
- `badge`: For status indicators (e.g., Pending, Allowed, Blocked).
- `button`: Core actionable element. Uses `--primary` (indigo) as its primary color.
- `card`: Surface container for wallet balances, transaction items, etc.
- `dialog`: For modal interactions (e.g., "Add Guardian", "Confirm Recovery").
- `input`, `label`: For data entry (Spend limits, addresses, etc.).
- `select`: Dropdown for selecting tokens or time windows.
- `separator`: Visual divider between sections.
- `sheet`: For the mobile navigation drawer.
- `skeleton`: Loading states for wallet balances and data fetches.
- `sonner`: Toast notifications (e.g., transaction success/failure).
- `switch`: On/off toggles (allow-list enforcement).
- `table`: For listing session keys and transaction history.
- `tabs`: For navigating the Policies page (Spend Limits | Session Keys | Allow-List).

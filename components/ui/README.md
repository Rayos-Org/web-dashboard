# UI Components

This folder contains all the low-level UI primitives generated by `shadcn/ui`.
**Do not hand-edit these files** unless you are intentionally modifying the core design system.
Instead, import them into your feature components and compose them or override their styles via `className`.

## Installed Primitives

- `alert`: For displaying inline warning/info states.
- `avatar`: For displaying user or guardian avatars.
- `badge`: For status indicators (e.g., Pending, Allowed, Blocked).
- `button`: Core actionable element. Uses `--primary` (Amber) as its primary color.
- `card`: Surface container for wallet balances, transaction items, etc.
- `dialog`: For modal interactions (e.g., "Add Guardian", "Confirm Recovery").
- `form`, `input`, `label`: For data entry (Spend limits, addresses, etc.) integrated with `react-hook-form` / `zod`.
- `select`: Dropdown for selecting tokens or time windows.
- `separator`: Visual divider between sections.
- `sheet`: For the mobile navigation drawer.
- `skeleton`: Loading states for wallet balances and data fetches.
- `sonner`: Toast notifications (e.g., transaction success/failure).
- `table`: For listing session keys and transaction history.
- `tabs`: For navigating the Policies page (Spend Limits | Session Keys | Allow-List).
